Pactole lets you record transactions in human-readable, git-friendly
`.pactole` files — in the spirit of [Beancount](https://beancount.github.io/docs/)
and Ledger-cli. The CLI validates and formats the journal, builds financial
reports and imports bank statements. A local web interface and a language
server provide additional ways to explore and edit the same files.

## Quick glance

```pactole
2026-01-01 open Assets:Checking
2026-01-01 commodity EUR
payee "Whole Foods"

2026-09-03 * "Whole Foods" "Weekly groceries"
  Expenses:Groceries 45.30 EUR
  Assets:Checking -45.30 EUR
```

```sh
pactole check my-ledger.pactole
pactole register my-ledger.pactole --account Expenses:Groceries
```

Reports, imports, the web interface and editor integrations are available in
addition to the commands shown above. See the
[overview](/tutorials/overview/) for the recommended workflow.
