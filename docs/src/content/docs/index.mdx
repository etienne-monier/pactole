Pactole lets you record your transactions in human-readable, git-friendly
`.pactole` files — in the spirit of [Beancount](https://beancount.github.io/docs/)
and Ledger-cli — and parse, check, format and query them from the command line.

## Quick glance

```pactole
2026-01-01 open Assets:Checking
2026-01-01 commodity EUR
payee "Whole Foods"

2026-09-03 * "Whole Foods" "Weekly groceries"
  Expenses:Groceries 45.30 EUR
  Assets:Checking -45.30 EUR
```

```sh
pactole check my-ledger.pactole
pactole register my-ledger.pactole --account Expenses:Groceries
```

Pactole is a work in progress: more commands (querying balances, reports, etc.)
are coming.
